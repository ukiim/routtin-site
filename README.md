# routtin.com

루띤(Ruttin) 앱의 공식 사이트. GitHub Pages로 서비스한다.

- `index.html` — 소개 · 지원 · FAQ · 사업자 정보 (App Store 지원 URL)
- `privacy/index.html` — 개인정보 처리방침 (한/영/일/중)
- `CNAME` — 커스텀 도메인 `routtin.com`

원본은 앱 저장소의 `docs/site/index.html`과 `docs/privacy-policy.html`이다.
고칠 때는 원본을 먼저 고치고 이곳으로 복사한다.
